Dialectical code-change deliberation as a standalone Python package · v0.1.0

Package layout

Voice dispatch CPYBUS-VOI-001

Loads voice prompts from disk, calls the Anthropic Messages API, extracts JSON from the response. Shared by all modes.

bus voices.py

Aggregation CPYBUS-AGG-001

Veto cascade on the three voice JSON outputs → Report. Priority: BLOCK → ESCALATE → REWORK → ADAPT → AGGREGATE.

bus aggregator.py

Public API CPYBUS-API-001

deliberate(proposal, context, mode, model) — single entry point, routes to the requested mode.

bus __init__.py

CLI CPYBUS-CLI-001

consilium deliberate and consilium check --diff. Wraps the public API with Click.

bus cli.py

Sequential mode CPYMOD-SEQ-001

Conservator → Generator → Control. Each voice sees all prior outputs. Cost: 3 API calls.

feature modes/sequential.py

Dialectic mode CPYMOD-DIA-001

Sequential + Skeptic challenger on the chosen candidate. Advisory by default; --skeptic-can-override for opt-in veto.

feature modes/dialectic.py

Trias mode CPYMOD-TRI-001

3 personality-biased Sequential runs dispatched in parallel via asyncio.to_thread. Pioneer (risk-tolerant) · Architect (balanced) · Steward (conservative). Democratic majority vote over the 3 chosen candidates.

Sequential

Default mode. Single shared context chain.

  • Voices: Conservator → Generator → Control
  • API calls: 3
  • Cost: ~$0.05–0.15 (Sonnet)
  • Confidence: from confidence_methodology (0–1)
  • Use when: routine changes, most decisions
consilium deliberate "..."

Dialectic

Sequential + Skeptic adversarial challenge.

  • Voices: Cons → Gen → Ctrl + Skeptic
  • API calls: 4
  • Cost: ~1.33× Sequential
  • Confidence: inherited from Sequential
  • Skeptic: sees chosen only · advisory default
  • Use when: medium-risk, or confidence < 0.7
--mode dialectic

Trias

3 parallel personality-biased deliberations.

  • Personalities: Pioneer · Architect · Steward
  • API calls: 9 (parallel)
  • Cost: ~3× Sequential
  • Confidence: 0.95 / 0.75 / 0.70 by vote pattern
  • No majority: ESCALATE
  • Use when: high-stakes, architecture decisions
--mode trias

Verdict reference

GO

All voices agree. Confidence ≥ 0.7. Proceed.

MODIFY

Proceed with changes. Confidence 0.4–0.7, or substantial disagreement addressed.

STOP

Confidence < 0.4. Deliberation too uncertain to proceed safely.

BLOCK

Hard veto: glossary_fail, irreversibility without consent, or Skeptic unaddressable (override mode).

ESCALATE

3+ simultaneous triggers (sequential), or no majority in Trias. Manual resolution required.

Veto cascade (sequential aggregation priority)

P1 glossary_fail (Control) → BLOCK
P2 irreversibility_flag (Conservator) → BLOCK
P3 3+ triggers simultaneously → ESCALATE
P4 substantial_disagreement (Control) → REWORK → MODIFY
P5 scale_down (Conservator meta) → ADAPT_SHORT → GO
P6 scale_up (Conservator meta) → ADAPT_EXTENDED → MODIFY
P7 default → AGGREGATE → GO / MODIFY / STOP by confidence
